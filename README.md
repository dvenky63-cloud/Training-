# ⚡ STACKLY | Next-Gen Enterprise Network & Compute

> High-throughput decentralized compute, low-latency telemetry routing, and post-quantum cryptographic network infrastructure.

---

## 📌 Executive Summary

**STACKLY** is an enterprise-grade, single-file landing page engineered for high-consequence edge compute clusters, space-grade orbital phased arrays, and hardware-level cryptographic enclaves. Built entirely with vanilla web technologies, it features an **Aurora Mesh Glass** aesthetic that blends light-mode clarity, liquid acrylic glassmorphism, and live interactive simulations.

---

## ✨ Key Features

- **Liquid Acrylic Glassmorphism**: Multi-layer frosted panels using `backdrop-filter: blur(28px) saturate(190%)`, specular rim highlights, and ambient light diffusion.
- **Hardware Showcase Stage**: Side-by-side presentation of Tier-IV datacenter server clusters and low-latency telemetry monitoring workstations over a geometric brand watermark.
- **Interactive Regional Backbone Telemetry**: Dynamic live state switcher between global hubs:
  - **AP-South (Hyderabad, IN)**: `0.14 ms` transit latency | `16,384` active tensor cores
  - **US-East (Virginia, US)**: `0.22 ms` transit latency | `32,768` active tensor cores
  - **EU-Central (Frankfurt, DE)**: `0.19 ms` transit latency | `24,576` active tensor cores
- **Real-Time Topology Plexus Engine**: 60 FPS HTML5 Canvas particle network featuring cursor repulsion, dynamic node budgeting, and device pixel ratio (DPR) optimization.
- **Dynamic IST Operating Hours**: Client-side timezone engine tracking the Hyderabad Regional Operations Center (Mon–Sat, 9:00 AM – 7:00 PM IST) with real-time status indication (`Open` / `Closed Now`).
- **Fully Responsive Architecture**: Fluid typography via CSS `clamp()` and adaptive CSS Grid/Flexbox layouts spanning desktop, tablet, and mobile viewports.
